# DAALab-AY225
The DAA-Lab Repo

This repository contains laboratory work for Design, Analysis and Algorithm Technologies (9407-AY225).

## Labs

### Preliminary Labs

- **PRELIM-LAB-WORK-1**: Console-based Python program implementing Bubble Sort algorithm for sorting numeric data in descending order with performance timing.

- **PRELIM-LAB-WORK-2**: GUI-based Java application for comparing sorting algorithms (Bubble Sort, Insertion Sort, Merge Sort) with visual interface and file upload support.

- **PRELIM-LAB-EXAM**: Comprehensive benchmarking tool for analyzing sorting algorithm performance on large datasets (up to 100,000 records) with structured CSV data, featuring multi-column sorting and performance metrics in a GUI-based Java application.

### Midterm Labs

- **MIDTERM-LAB-1**: Interactive HTML application implementing Dijkstra's algorithm for multi-criteria shortest path analysis (distance, time, fuel) with graph visualization, Excel data import, and optimal route recommendations.

- **MIDTERM-LAB-2**: Cavite Network Node Map & Shortest Path Finder - CLI-based Python program and interactive browser-based visualization for finding shortest paths between Cavite locations using Dijkstra's algorithm with multiple criteria (Distance, Time, Fuel).
