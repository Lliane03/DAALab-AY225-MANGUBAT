# DAALab-AY225
The DAA-Lab Repo

This repository contains laboratory work for Design, Analysis and Algorithm Technologies (9407-AY225).

## Labs

- **PRELIM-LAB-WORK-1**: Console-based Python program implementing Bubble Sort algorithm.
- **PRELIM-LAB-WORK-2**: GUI-based Java application for comparing sorting algorithms (Bubble Sort, Insertion Sort, Merge Sort).
- **PRELIM-LAB-EXAM**: Comprehensive benchmarking tool for analyzing sorting algorithm performance on larger datasets with structured CSV data running in a GUI-based Java application.
- **MIDTERM-LAB-WORK-1**: Interactive HTML application implementing Dijkstra's algorithm for multi-criteria shortest path analysis (distance, time, fuel) with graph visualization, Excel data import, and optimal route recommendations.
